              Tableau Interactive Dashboard / Marketing Monetization

Інтерактивна вітрина даних та візуалізація ключових маркетингових і монетизаційних метрик проєкту.
./(https://public.tableau.com/views/MarketingMonetization/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link) 

Структура та блоки дашборду
1. Roas & Cost (Динаміка часового ряду):
    Комбінована діаграма (Dual Axis Chart) для відстеження співвідношення витрат (`Cost`) та окупності (`ROAS calc`) у часі.
2. Key Performance Metrics (Загальні KPI):
     Сводна таблиця агрегованих показників: `Cost`, `CPI`, `Profit`, `ROAS calc`, `Total Revenue`.
3. Campaign's Profit (Прибутковість кампаній):
    Горизонтальна гістограма для порівняння кампаній за рівнем згенерованого чистого прибутку (`Profit`).
4. Media Source Analysis (Джерела трафіку):
    Таблична розбивка ключових метрик у розрізі медіа-джерел (`googleadwords_int`, `other` тощо).
