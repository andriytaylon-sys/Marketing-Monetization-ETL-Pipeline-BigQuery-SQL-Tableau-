Розрахунки
Уся розрахункова відносна аналітика (ROAS, CPI) на рівні вітрини обраховується для базової перевірки
якості даних, але під час підключення до Tableau реалізована через агреговані обчислювані поля.
Це виключає проблему повторного підсумовування коефіцієнтів при зміні рівнів
деталізації .
Для забезпечення повної точності аналітики в Tableau було створено виділені розрахункові поля з
використанням функцій агрегації.

Сумарний дохід
(Total Revenue)
Total Revenue = SUM(Ad Revenue) + SUM(In App Revenue)
Об'єднує обидва монетизаційні канали - рекламні покази та внутрішньоігрові / внутрішні
-/додаткові покупки.

Чистий Прибуток
(Profit)
Profit = SUM(Total Revenue) - SUM(Cost)
Абсолютний фінансовий результат кампанії. Від'ємне значення вказує на збитковість
закупівлі трафіку.

Окупність Рекламних Витрат
(ROAS — Return on Ad Spend)
ROAS = SUM(Total Revenue) / SUM(Cost)
Розраховується виключно через суму доходу, поділену на суму витрат. Неагреговане
ділення призводить до помилки сумування відсотків.

Вартість Установки
(CPI — Cost Per Install)
CPI = SUM(Cost) / SUM(Installs)
Показує середню ціну залучення одного користувача на відповідному рівні фільтрації
