 Marketing-Monetization-ETL-Pipeline-BigQuery-SQL-Tableau

Мета проєкту — побудувати скрізний SQL-пайплайн у Google BigQuery для об'єднання чотирьох окремих джерел даних (витрати, установки, дохід від реклами IAA, дохід від покупок IAP) та підготувати очищену вітрину даних для подальшої візуалізації та аналізу в Tableau.

Архітектура рішення та джерела даних

У межах завдання було опрацьовано 4 сирі таблиці з датасету `mornhouse-test-environment.test_app_dataset`:
1. `cost_table` — витрати на рекламні кампанії (Cost).
2. `non_org_installs_report` — планові/неорганічні установки (Installs).
3. `ad_revenue_raw` — дохід від внутрішньододаткової реклами (In-App Ads / IAA).
4. `in_app_events_report` — дохід від внутрішньоігрових покупок (In-App Purchases / IAP).
Нормалізація та очищення даних:
   Застосовано `LOWER(TRIM(...))` для полів `media_source` та `campaign` для усунення дублікатів через різний регістр або випадкові пробіли.
   Приведено коди країн до єдиного стандарту за допомогою `UPPER(TRIM(country))`.
   Зведення даних :
   Використано CTE (`combined_data`) для консолідації витрат, залучення та монетизаційних подій в єдиний структурований датасет.
   Захист від помилок розрахунку:
   Використано функцію `SAFE_DIVIDE()` для запобігання помилкам ділення на нуль (`Division by zero`) при розрахунку CPI та ROAS.
